Working Guide

How to Use the App

  1. 01
    Launch the Application
    Open PPTX to PDF Merger from the Desktop shortcut created during installation. A branded splash screen will appear while the app initializes PowerPoint integration.
  2. 02
    Select Your Source Folder
    Click Browse and choose the folder containing your .pptx files. The app automatically scans for all PowerPoint files and lists them in the queue.
  3. 03
    Arrange the File Order
    Select any file in the list and use the Move Up / Move Down buttons to reorder them. The final PDF pages will follow this sequence exactly.
  4. 04
    Set the Output Filename
    Enter your desired output filename in the Output PDF field. The .pdf extension is appended automatically if omitted. The merged file saves into the same source folder.
  5. 05
    Convert & Merge
    Click the green Convert & Merge button. The app opens each PPTX silently via PowerPoint COM, exports it to a temporary PDF, then merges all temporary PDFs into the final output using pypdf. Temp files are cleaned up automatically.
  6. 06
    Monitor Progress in the Log
    The log panel at the bottom shows real-time status for each file conversion, the merge step, and any errors. A progress bar tracks overall completion (0–100%). A success dialog confirms the output path when finished.
Installation

Install on Windows

The fastest way to install is via PowerShell. Open PowerShell as Administrator and paste the command below. The installer downloads the latest release, extracts it to Program Files, and places a Desktop shortcut.

PowerShell (Run as Administrator)
irm "https://raw.githubusercontent.com/Prabhath528/pptx-to-pdf-merger/refs/heads/main/online_install.ps1" | iex
  1. Open PowerShell as Administrator — Right-click the Start button and choose Windows Terminal (Admin) or Windows PowerShell (Admin).
  2. Paste and run the command above. The installer shows a splash screen, displays the License Agreement, and asks for your acceptance (Y to continue).
  3. Files are downloaded and extracted to C:\Program Files\PPTX to PDF Merger automatically.
  4. A Desktop shortcut is created pointing to main.exe. Launch the app directly from your Desktop.
Prerequisite: Microsoft PowerPoint must be installed on your Windows machine. The app uses PowerPoint's COM automation interface to ensure pixel-perfect PDF conversion. Internet connection is required during the install command to download the release package.
